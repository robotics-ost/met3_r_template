◆ motor_model_calc_voltage()

void motor_model_calc_voltage ( const float * Q,
const float * qd,
float * U )

Calculates the required motor voltage based on the desired joint force/torque and velocity.

The calculation is based on the motor model equations:

\[I = \frac{M}{k_M},\quad M = \frac{Q}{i}\]

\[U = R\cdot{}I + k_M\cdot{}\omega,\quad \omega = q\cdot{}i\]

Input shaft torque and angular velocity are limited to the maximum values defined in the motor configuration.

Note
Depending on the number of motors set in the configuration, this function accepts either a scalar or a vector.
Parameters
QPointer to desired joint force/torque [N or Nm].
qdPointer to desired joint velocity [rad/s or m/s].
UPointer to return the calculated motor voltage [V].
