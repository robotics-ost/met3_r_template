Detailed Description

Owns the UDP link to a single ESP32.

Sends HELLO/GOODBYE/commands, and runs a background thread that parses incoming telemetry and dispatches it to registered callbacks.

Usage:

client = UdpClient("192.168.1.50") # or a hostname:
client = UdpClient("esp32-robot.local")
client.on_telemetry(my_callback)
client.start()
...
client.send_move_to(1.0, 0.5, 0.0)
...
client.stop()

Parameters

portUDP port the ESP32 listens on.
local_portLocal UDP port to bind to. Defaults to the same value as port (matching the firmware's expectation of a symmetric port on both ends).
recv_bufsizeMaximum UDP payload size to read per recvfrom().
socket_timeout_sReceive timeout, in seconds; controls how responsively the receiver thread notices stop() being called.
