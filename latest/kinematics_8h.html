void kinematics_calc_fw_kin_odom ( const float qd[2],
float xi[3],
float xid[3] )

Calculates forward kinematics and odometry for a differential drive robot.

This function computes the robot's pose and velocity in the global frame based on the wheel velocities.

The calculations are based on the following equations:

  • Forward kinematics in the robot frame:

    \[{}^{R}\dot{\xi}_{R} = {}^{R}J_{W}\left(q\right)\cdot{}\dot{q} \]

  • Rotation from robot frame to global frame:

    \[{}^{G}\dot{\xi}_{R} = {}^{G}R_{R}\cdot{}^{R}\dot{\xi}_{R} \]

  • Integrate velocities to update the robot pose in the global frame (odometry):

    \[{}^{G}\xi_{R} = \int{}^{G}\dot{\xi}_{R} dt + {}^{G}\xi_{R,0} \]

Parameters
qdPointer to the wheel velocities [rad/s]. Index 0: left wheel, index 1: right wheel.
xiPointer to the robot pose [x, y, phi] in the global frame [m, m, rad].
xidPointer to the robot velocities [vx, vy, omega] in the global frame [m/s, m/s, rad/s].

void kinematics_calc_inv_kin ( const float xid_d[3],
float qd_d[2] )

Calculates inverse kinematics for a differential drive robot.

This function computes the required wheel velocities to achieve the desired robot velocities in the robot frame. The calculations are based on the following equations:

\[\dot{q} = {}^{W}J_{R}\left(q\right)\cdot{}{}^R\dot{\xi}_{R} \]

Parameters
xid_dPointer to the desired robot velocities [vx, vy, omega] in the robot frame.
qd_dPointer to the required wheel velocities [rad/s]. Index 0: left wheel, index 1: right wheel.
