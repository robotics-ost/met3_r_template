Detailed Description

Shared UDP telemetry/command core for the ESP32 link.

This module owns:

  • the wire protocol (struct formats, packet building/parsing)
  • the socket + background receiver thread
  • a small callback/observer API for telemetry
  • typed send_*() methods for every command

It intentionally knows nothing about GUIs or ROS2. Both the web GUI (gui_web/app.py) and the ROS2 node (ros2_ws/.../bridge_node.py) import this module and drive it through UdpClient. If you only ever change one file when the ESP32-side protocol changes, it should be this one.
