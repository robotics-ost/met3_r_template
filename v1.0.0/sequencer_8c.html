◆ sequencer_task()

void sequencer_task ( void * arg)

The main task function for the sequencer.

This function runs in a FreeRTOS task and processes the sequencer steps in the queue. It handles the execution of MOVE_TO_POSE and WAIT steps based on their types.

Parameters
argPointer to any arguments passed to the task (not used).
