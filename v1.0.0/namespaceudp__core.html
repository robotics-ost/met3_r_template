◆ find_config_path()

Optional[Path] find_config_path ( Optional[str] explicit_path = None)

Locate an esp32_config.json file using a fixed search order.

Resolution order:

  1. explicit_path argument
  2. ESP32_CONFIG_PATH environment variable
  3. ./esp32_config.json (current working directory)
  4. <repo_root>/esp32_config.json (repo root = parent of this file's parent, i.e. host_interface/ when this file is at core/)
Parameters
explicit_pathOptional explicit path that, if given, is checked first and takes priority over every other location.
Returns
The first existing config file path found, or None if none of the candidate locations exist.

◆ parse_telemetry()

Optional[TelemetryBatch] parse_telemetry ( bytes data)

Parse a raw UDP payload into a TelemetryBatch.

Validates the magic byte and message type, then decodes as many safety/control samples and sequencer steps as both the declared counts in the header and the actual buffer length allow (truncated/corrupt packets are handled gracefully by simply stopping early).

Parameters
dataRaw bytes received from the socket.
Returns
A populated TelemetryBatch, or None if data is too short, has the wrong magic byte, or is not a telemetry message.

◆ resolve_host()

str resolve_host ( str host)

Resolve a hostname to an IPv4 address.

Plain dotted IPv4 addresses are returned unchanged. Regular DNS hostnames and mDNS '.local' names (e.g. an ESP32 advertising itself as 'esp32-robot.local') are resolved via the OS resolver – note that '.local' resolution requires mDNS support to be set up on this machine (built in on macOS; on Linux needs avahi-daemon + libnss-mdns; on Windows needs Bonjour/iTunes or similar).

Parameters
hostDotted IPv4 address or hostname to resolve.
Returns
The resolved IPv4 address as a string.
Exceptions
RuntimeErrorif host is not a valid IPv4 address and could not be resolved via DNS/mDNS.
