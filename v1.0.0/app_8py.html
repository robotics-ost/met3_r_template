Detailed Description

Web GUI backend for the ESP32 UDP link.

Built entirely on top of core/udp_core.py – this file only wires that core to a browser:

ESP32 --UDP--> UdpClient --callback--> SSE broadcast --> browser (Chart.js)
browser --fetch POST--> Flask routes --> UdpClient.send_*() --UDP--> ESP32
